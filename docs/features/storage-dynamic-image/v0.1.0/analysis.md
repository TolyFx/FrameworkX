# 本机图片动态变体 — 功能分析

## 概述

在 FrameworkX 存储读取链路中增加按请求动态缩放、裁切和转码能力。私有资源由宿主认证并解析 `Scope`；宿主明确公开的本机图片可通过受限文件根目录按路径读取。图像扩展负责纯字节变换，Axum 适配器负责参数、路径安全与 HTTP 响应。

## 一、交互链

**用户故事**：作为已认证的资源消费者，我想在访问本机图片时指定目标尺寸和适配方式，以便按页面实际展示尺寸获取图片。

```mermaid
flowchart LR
    A[请求图片并携带尺寸] --> B[服务端校验身份与参数]
    B --> C[读取当前 Scope 的原图]
    C --> D[缩放裁切与转码]
    D --> E[返回目标图片]
```

请求示例：`GET /storage/files/42/content?w=240&h=135&fit=cover&q=80&format=webp`。未携带 `w/h` 时保持原图和 `variant=thumbnail` 的既有行为。

公开本机图片示例：`GET /uploads/original/2026/08/example.jpeg?w=240&h=135&fit=cover&q=80&format=webp`。公开路由仅允许访问宿主配置根目录内的图片，拒绝路径穿越和非图片文件。

## 二、逻辑树

### 事件流

| 时刻 | 事件 | 处理 | 产生的新事件 |
|---|---|---|---|
| T0 | 请求文件内容 | Bearer Token 解析为 Scope | 查询文件对象 |
| T1 | 携带 `w` 或 `h` | 校验尺寸、像素、fit、质量和格式 | 读取原图字节 |
| T2 | 原图读取成功 | 调用图像处理端口 | 返回变体字节及 MIME |
| T2' | 参数或类型非法 | 映射为 400 错误 | 停止处理 |
| T2'' | 文件不属于 Scope | 返回未找到 | 不泄露跨 Scope 资源 |

### 状态流转

| 实体 | 触发事件 | 前状态 | 后状态 | 回退策略 |
|---|---|---|---|---|
| 文件内容 | 合法变体请求 | 原始字节 | 临时变体字节 | 原图不修改 |
| HTTP 请求 | 参数越界 | 待处理 | 拒绝 | 不读取和处理图片 |
| HTTP 请求 | 图像解码失败 | 处理中 | 失败 | 返回统一存储错误 |

## 三、功能编号与网络定位

| 编号 | 功能节点 | 层级 | 简介 |
|---|---|---|---|
| I-4 | 动态图片变体端口 | 基础设施 | 定义与具体图像库无关的变换协议 |
| I-5 | 本机图片变体适配器 | 基础设施 | 使用 `image` crate 实现缩放、裁切和编码 |

| 依赖 | 依赖方式 | 当前状态 | 风险 |
|---|---|---|---|
| `StorageBackend` | 按归属文件路径读取字节 | 已有 | 大原图读取占用内存 |
| `MetadataExtractor` | 扩展纯字节变换端口 | 已有并扩展 | 自定义实现可选择不支持 |
| `ScopeResolver` | 鉴权与归属隔离 | 已有 | 宿主必须正确装配 |

| 接口 | 定义方 | 消费方 | 输入输出 | 敏感度 |
|---|---|---|---|---|
| `GET /storage/files/{id}/content` | `fx_storage_axum` | 宿主客户端 | `w/h/fit/q/format` → 图片字节 | 私有资源 |
| `GET /uploads/original/{path}` | `fx_storage_axum` | 公开客户端 | `w/h/fit/q/format` → 图片字节 | 宿主明确公开的资源 |
| `MetadataExtractor::transform_image` | `fx_storage_service` | `fx_storage_image` | 原图字节与变换规格 → 变体 | 内部协议 |

## 四、验收标准与结论

- 支持 `contain`、`cover`、`fill`。
- 支持单边等比缩放或双边目标尺寸。
- 支持 WebP、JPEG、PNG 输出；JPEG 应用质量参数。
- 单边最大 4096，双边最大 1600 万像素，质量范围 40–95。
- 原图、固定缩略图和非图片文件读取契约保持兼容。
- 公开本机图片路由限制在宿主配置根目录，拒绝符号链接越界和非图片扩展名。
- 首版按请求即时处理，不持久化派生图；高流量场景后续增加派生缓存或接入 OSS 图片处理。
